# Forest Parallax Website 🌲

The **Forest Parallax Website** is a visually immersive landing page that demonstrates a smooth **parallax scrolling effect**, creating a sense of depth by moving foreground and background elements at different speeds.

This project focuses on **visual storytelling**, scroll-based animations, and clean UI composition using core web technologies.

---

## ✨ Key Highlights

- Smooth parallax scrolling animation
- Layer-based movement (text, birds, forest, rocks, water)
- Fullscreen hero section
- Clean and minimal navigation bar
- Scroll-driven visual storytelling
- Lightweight implementation (no external libraries)

---

## 🛠 Tech Stack

- **HTML5** – Semantic page structure  
- **CSS3** – Layout, typography, and visual styling  
- **JavaScript (Vanilla)** – Scroll-based parallax logic  

No frameworks. No shortcuts. Pure fundamentals.

## ⚙️ How It Works

- As the user scrolls, JavaScript listens to the `scroll` event.
- Different elements move at different speeds using `transform` and positional offsets.
- Foreground elements move faster than background elements.
- This creates an illusion of depth and motion.
